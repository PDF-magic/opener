# Detect hidden active content in PDF revision history (opener-0450)

The opt-in `pdf_revision_active_content.inspect_pdf_revision_active_content(bytes)` runs the previously validated `/Prev` chain inspection and parses each historical PDF snapshot. It examines indexed objects, including orphan objects and nested direct dictionaries, for JavaScript, URI/Launch, interactive form, automatic action, multimedia, XFA, and embedded-file indicators.

An object is reported as **hidden** when its historical `(object ID, generation, byte offset)` location is absent from the final cross-reference view, including when a later revision replaces an active object with an inert object of the same number. The immutable result includes revision count, number of historical objects containing active markers, number hidden by later revisions, and fixed hidden-category identifiers; no filenames, URLs, scripts, or raw content are emitted. Results always have `permits_open=False`.

This is **passive detection**, not a script interpreter, attachment decoder, document clean verdict or activation of Enhanced protection. Parsing is bounded to 16 MiB, 16 revisions, 8,192 combined xref objects, 65,536 nested container nodes and 512 active historical objects. Missing dependencies, encrypted or malformed documents, ambiguous historical EOF markers, unsupported compressed object streams and exhausted budgets fail closed. This inspector intentionally does not resolve indirect references inside active action dictionaries because all indexed objects are examined separately.

CI exercises overwritten malicious and benign object fixtures, historical orphaned actions, active multimedia and attachment references, nested action dictionaries, invalid revision chains, resource limits, privacy and non-interference with the installed Built-in ClamAV gate. The existing scan, quarantine, cache, signature checks, profile selection and saved user preferences remain unchanged. Future production orchestration must enforce execution isolation and the independent mandatory scan requirements before acting on these findings.
