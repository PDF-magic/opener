# View Sanitized PDF (opener-0553)

A future Maximum UI can show **View Sanitized PDF** only when
`maximum_view_sanitized_pdf.available_view_sanitized_pdf_action(offer)`
returns fixed presentation metadata for a verified, passive, rasterized
`SanitizedCopyOffer`. The offered copy is marked as generated content,
not the untouched original. Checking availability does **not** save,
scan, open, or authorize a PDF.

When the user expressly chooses View, the trusted coordinator calls
`view_sanitized_pdf(offer, user_requested=True)`. It stages the verified
generated bytes in the existing exclusive, private, 0600 temporary PDF and
delegates to `maximum_safe_copy_handoff._scan_staged_copy`, which reuses
the existing `scan_and_open_generated_copy` ClamAV and PDF launch gate.
That gate requires a **fresh, non-cached scan**, validates exact output
bytes, honors signature freshness, file-integrity checks, quarantine and
the user-selected destination. An invalid offer, absent consent, failed
scan, unexpected result, or swapped file blocks viewing. **Never open the
original PDF as a fallback.** This is a viewer action, not the separate
Save Sanitized Copy action (opener-0544).

On successful launch, the returned `SanitizedPDFViewSession` retains its
ownership-checked private file until the trusted coordinator knows the
viewer has finished. **Do not release it immediately after launch.** Call
`session.release_after_viewer_closes()` when the viewer no longer requires
the path. Failed attempts clean only their own unchanged temporary
file; substituted files are not followed or deleted. Public metadata
contains no private paths and does not authorize opening the original.

The installed application still has only the Built-in scanning policy.
Maximum is not selectable and has no end-to-end coordinator feeding this
action actual offers. Exposing it in the installed UI requires that
separately reviewed integration; this task provides a callable, tested
action and presentation contract, not a bypass or a simulated completed
conversion. It does not change scanner behavior or preferences.
